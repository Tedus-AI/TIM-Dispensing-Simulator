# TIM 點膠研究室 v1.8.1

本機工程假設原型，**未經實機校準**。模擬 Laird Tputty 910／Tgrease 2500 在 R75 氣壓時間式或 P300 PCP 容積式設備上的點膠、收尾、透明板壓合與一維熱阻，用於比較方案、縮小試驗範圍，不能取代首件或量產驗證。自動最佳化改版（針嘴與速度、設備上限、米字形、出膠量校正）見 [第 29 份](../29_v1.8最佳化針嘴速度與設備上限.md)；介面整潔化與判定說明見 [第 28 份](../28_v1.7介面整潔化與判定說明.md)；最佳化搜尋變數見 [第 27 份](../27_v1.6最佳化搜尋變數.md)；最佳化審核、精細度與並行見 [第 26 份](../26_v1.5最佳化審核與搜尋精細度.md)；介面重整、膠量列與針距膠形見 [第 25 份](../25_v1.4膠量列分頁重整與針距膠形.md)；製程窗口最佳化見 [第 24 份](../24_v1.3製程窗口最佳化與針嘴匹配.md)；壓合與夾氣模型見 [第 23 份：v1.1 可壓縮夾氣與墊片壓合](../23_v1.1可壓縮夾氣與墊片壓合.md)；v1.0 的修正與查證見 [第 22 份](../22_v1.0接手全面修正與驗證.md)。

## 開啟

網頁版：https://tedus-ai.github.io/TIM-Dispensing-Simulator/ （`.github/workflows/pages.yml` 在 main 更新後自動測試、建置並部署；建置使用相對路徑，同一份 `dist` 也能由本機啟動器開啟）。

Windows：雙擊本資料夾的 **啟動模擬器.cmd**，瀏覽器開啟 `http://127.0.0.1:5173/`。只需 Node.js；建置檔已附於 `dist/`，執行時不連外部 CDN，工件不上傳雲端，只監聽本機。

開發：

```powershell
npm ci
npm test        # 107 項數值、幾何與壓合測試（含 Stefan、Taylor–Saffman、pV 驗證）
npm run dev     # 開發伺服器，與啟動器共用 5173，請勿同時開
npm run build   # 更新 dist/
```

## 操作流程

1. **熱源工件**：元件接觸面的形狀、尺寸、中心、組裝間隙（墊片厚度）與功耗；「工件」群組內為平板尺寸、治具高度，或匯入 STL／GLB／內嵌 glTF。
2. **膠材設備**：膠材、架構、壓力（psi／bar）或轉速、針頭規格（G 數，選了會自動填入內徑）與虛擬針嘴內徑（可自行輸入，「?」有 G 數對照表）。每個欄位都標示「TDS／推導／AI 初估／幾何」。「用實測出膠量校正」：原地連續出膠後秤重，輸入重量與時間，調整等效黏度（Tgrease）、參考流率（Tputty）或容積效率（P300）。
3. **路徑**：依熱源（中心線、N、蛇形、螺旋、米字形、外框）、直線或單點；設定速度、加速度、轉角減速與針嘴離面高度。
4. **收尾**：提前關膠、終點停留、退離方式、PCP 反轉。
5. **壓合**：夾氣處理、壓合力、下降速度上限、有效黏度、降伏應力、靜置觀察時間、估算網格。

膠量列（分頁上方，固定顯示）：需求（熱源面積 × 間隙）、目前沉積（mL、g）與比值。

- 目標可用三種單位：× 需求、mL、g。
- 按「套用」後依調整方式反推：

  | 路徑 | 預設 | 也可選 |
  |---|---|---|
  | 線與圖樣 | 調壓力（P300 調轉速），到極限才改速度 | 只調速度 |
  | 單點 | 調開膠時間 | 調壓力 |

  提示會寫出改了哪個設定。

- 頂部工具列：「自動最佳化」「情境比較」（v1.7 移除與最佳化重疊的「圖樣比較」）。
- 說明：介面上的「?」游標移過去（手機點一下）才顯示說明。

播放：空白鍵播放／暫停；拖曳時間軸、點曲線或時間軸上的標記（關膠、到位、抬針、退離）可跳轉。播放倍率只影響觀看速度。

壓合：「模擬壓合」顯示透明板以定力壓到墊片、膠膜擴散、氣泡（紅色）壓縮／遷移／排出，以及壓到墊片後的靜置回脹；時間軸標示壓合秒數與靜置秒數。右側列出覆蓋率、夾氣、溢出距離、溫升、熱阻、壓到墊片時間、氣泡封住／排出次數與回脹程度；可切換「前緣時序」著色、切換夾氣顏色（洋紅、藍、黃、黑）、保存壓合基準。

情境：結果卡「存成情境」保存目前參數與壓合結果（未壓合會自動先算），右上「情境比較」依目標（覆蓋 ≥ 目標、溢膠 ≤ 上限，達標者膠量越少越前）排序全部情境，可載入、改名、刪除、匯出 CSV／JSON、匯入 JSON；情境存在瀏覽器的 localStorage。

自動最佳化（製程窗口）：頂部「自動最佳化」固定圖樣、熱源、間隙、膠材、加速度、針距、收尾與壓合條件，搜尋間距（蛇形／螺旋）與邊界內縮；直線與單點沒有圖樣幾何，只搜尋膠量窗口（v1.4）。每組幾何找出膠量窗口（左界＝達到覆蓋目標的最少膠量，右界＝溢膠不超過上限的最多膠量），標稱膠量需在 ±容差（預設 ±10%）內兩界都成立才算達標；前 3 名以設定網格在 −容差／標稱／+容差 複核。膠量預設以驅動壓力（R75，10–100 psi）或 PCP 轉速（P300，10–150 rpm）在目前速度下調整，到極限才改速度（單點改開膠時間）；也可只調速度（單點：開膠時間）並設週期上限。調整方式與膠量列共用。針嘴可固定，或選「自動」與移動速度一起依出膠能力與膠條選（v1.8，見下）。

v1.6 起有「搜尋變數」表：

- 圖樣種類（蛇形、螺旋、米字形、單點、中心線）、路徑間距、邊界內縮、螺旋起點、移動速度、針嘴，每個都能選「固定」或「搜尋」，範圍可自訂。
- 每種圖樣的最佳組都會找膠量窗口。

v1.8 起針嘴（預設「自動」）與移動速度（預設「搜尋」）不再逐一壓合，而是每組幾何先用解析解選好：

- 針頭只試整數 G 數（25G 0.25 mm 到 8G 3.43 mm，共 16 種）；1/8 吋（Laird 指南用嘴）只在設備頁手動選。
- 條件：只靠壓力（轉速）就鋪得出整個膠量範圍（預設容差時 0.94–1.40× 需求）。
- 選法：膠條最接近針嘴大小、週期不超過週期上限（未設定時以 30 s 為參考），成本相近時選週期短的。
- 走完路徑在速度範圍內都超過 180 s 的組合先略過；出不了需要膠量的組合在表格標示「設備上限 x×」。
- 達標者膠量相差 3% 以內時，依膠條、週期、壓力餘裕排序。

v1.5 起有四個精細度：快速、標準、精細、極精細。差別在候選數、找窗口與複核的組數、容差內的複核點數與網格。

- **時間估算**：選級時依這台電腦試算一次估出時間。
- **並行**：搜尋分散在多個 Worker 執行。
- **停止**：搜尋中按「停止搜尋」，會保留已完成的部分結果。
- **達標條件**：只有在細網格、容差內多個膠量都達標的結果才算「達標」。
- **套用**：網格會設成該結果使用的網格。

這是模擬器上的數值搜尋，不是統計學習；設計理由見上層第 24、26 份文件。

針嘴與膠形：同樣每 mm 膠量下，膠條的高與寬由針嘴離面高度決定；針嘴內徑決定出膠量與膠條品質。

- 針距低於膠的自然高度時，膠被壓成針距高、較寬的扁條（截面積不變）。
- 壓平寬度以「內徑 + 2 × 針距」為上限（AI 初估）；再壓不開時，膠高於針距，標示「埋針」。
- 結果卡另顯示拉細倍率（針嘴內孔截面 ÷ 實際膠條截面＝平均移動速度 ÷ 出膠速度）與匹配內徑 √(4A/π)（A＝每 mm 路徑膠量），0.7–1.5 為 AI 初估的良好範圍。

時間曲線：退離完成後的灰色區域是尾膠結算（關膠後衰減出膠積分 20 個時間常數，讓帳目閉合），不是機台等待；週期時間以「動作完成」計。

視角：全機、工作區、機頭、供膠站（P300）、近看、熱源特寫、跟隨；①–④ 等角方向、360° 自由旋轉、正交／透視切換、深色／淺色主題。近看與熱源特寫會隱藏上方機構，不改變任何尺寸。

## 模型摘要

| 項目 | 方法 | 界線 |
|---|---|---|
| R75 putty 流量 | TDS 75 g/min @ 90 psi × 冪律管流 Q ∝ P^m·d^(3+m)/L^m，m = 2.7 取自 Laird 910 點膠指南曲線 | 指南與 TDS 的流率單位待 Laird 確認；未含溫度 |
| R75 grease | 常黏度 2500 Pa·s Poiseuille | 單點黏度，非完整流變 |
| P300 | 理想容積計量 0.3 mL/rev | 滿腔、無滑漏、無管路壓降 |
| 起停 | 延遲 + 一階響應解析積分 | 時間常數為 AI 初估 |
| 運動 | 梯形速度；多段路徑轉角依 junction deviation 減速 | 通用近似，非特定控制器 |
| 膠形 | 半橢圓膠線（共享截面環）、球冠膠點，體積守恆；針距低於自然高度時壓成針距高（寬度以內徑 + 2 × 針距為限） | 幾何重建，非潤濕或拉絲求解；壓平範圍為 AI 初估 |
| 壓合 | 定力壓到墊片的 Hele-Shaw 擠壓（時間由力平衡決定）；夾氣依 pV = 常數 隱式聯立，介面雙向移動（壓縮、遷移、排出），墊片定位後依 Bingham 降伏應力回脹 | 等效牛頓黏度；壓合中不計降伏應力；指狀穿透以網格一階近似，夾氣數量對網格敏感 |
| 熱阻 | (間隙/k + TDS 推算接觸熱阻) ÷ 濕潤面積 | 一維，不含擴散熱阻 |

完整參數與出處在介面右上「來源」；v1.0／v1.1 查證後的更新放在 `src/parameters.js`，研究原檔 `../data/engineering_defaults_v0.3.json` 保持不變。

## 程式結構

| 檔案 | 內容 |
|---|---|
| `src/engine.js` | 流量、起停、沉積、收尾、體積帳目；不逐步模擬的沉積與時間（runTiming）、出膠量校正 |
| `src/motion.js` | 梯形運動與轉角前瞻規劃 |
| `src/path-planning.js` | 依熱源產生路徑（含米字形） |
| `src/compression.js` | 壓合（定力 Hele-Shaw、可壓縮夾氣、靜置回脹）、熱阻 |
| `src/tuning.js` | 依目標膠量反推壓力／轉速（到極限改速度或開膠時間）、速度、開膠時間；對數空間夾擠割線法 |
| `src/optimize.js` | 目標判定與排序、製程窗口搜尋（四個精細度、可並行、可停止）、時間估算、針嘴與速度選擇（chooseProcess） |
| `src/compute-worker.js` | 壓合、膠量反推、最佳化單次評估與計時的背景計算（最佳化時開多個） |
| `src/parameters.js`、`src/materials.js` | v1.0 參數更新與材料卡 |
| `src/scene.js`、`src/scene-parts.js` | 3D 場景、龍門機構、相機 |
| `src/cartridge-assembly.js`、`pcp-head.js`、`pump-station.js`、`c300-enclosure.js` | 依公開尺寸的設備外形 |
| `src/compression-scene.js` | 壓合視覺化 |
| `src/main.js`、`src/ui/`、`src/style.css` | 介面 |
