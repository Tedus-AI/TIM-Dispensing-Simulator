## 開啟

網頁版：https://tedus-ai.github.io/TIM-Dispensing-Simulator/ （`.github/workflows/pages.yml` 在 main 更新後自動測試、建置並部署；建置使用相對路徑，同一份 `dist` 也能由本機啟動器開啟）。

Windows：雙擊本資料夾的 **啟動模擬器.cmd**，瀏覽器開啟 `http://127.0.0.1:5173/`。只需 Node.js；建置檔已附於 `dist/`，執行時不連外部 CDN，工件不上傳雲端，只監聽本機。

開發：

```powershell
npm ci
npm test        # 143 項數值、幾何與壓合測試（含 Stefan、冪律圓盤、Taylor–Saffman、pV、Bingham 塑性極限、氣壓起停積分、向心加速度、膠溫、膠點壓合封閉解、機台行程干涉）
npm run dev     # 開發伺服器，與啟動器共用 5173，請勿同時開
npm run build   # 更新 dist/
```

## 操作流程

1. **熱源工件**：元件接觸面的形狀、尺寸、中心、組裝間隙（墊片厚度）與功耗；「工件」群組內為平板尺寸、治具高度，或匯入 STL／GLB／內嵌 glTF。
2. **膠材設備**：膠材、架構、膠溫（v3.0：膏體越熱越稀，旁邊顯示相對 23 °C 的稠度與膠量倍率）、壓力（psi／bar）或轉速、針頭規格（G 數，選了會自動填入內徑）與虛擬針嘴內徑（可自行輸入，「?」有 G 數對照表）。每個欄位都標示「TDS／推導／AI 初估／幾何」。「用實測出膠量校正」：原地連續出膠後秤重，輸入重量與時間，調整稠度 K（Tgrease）、參考流率（Tputty）或容積效率（P300）；再填一組不同壓力的量測，會一併擬合剪切變稀指數 n（Tgrease）或壓力冪次 m（Tputty）。
3. **路徑**：依熱源（中心線、N、蛇形、螺旋、米字形、外框）、直線或單點；設定速度、加速度、轉角減速與針嘴離面高度。
4. **收尾**：提前關膠（預設 0 mm：到終點才關膠；保留「比較值 10 mm」按鈕）、終點停留、退離方式、PCP 反轉。
5. **壓合**：夾氣處理、壓合力、下降速度上限、稠度 K 與剪切變稀指數 n（預設與出膠相同）、降伏應力、靜置觀察時間、保壓時間上限、估算網格。「用透明板實測校正壓合」（v3.0）：點一顆膠、秤重、用已知的力壓一段時間、量攤開的直徑，反推壓合用的稠度 K 或降伏應力。

膠量列（分頁上方，固定顯示）：需求（熱源面積 × 間隙）、目前沉積（mL、g）與比值。

- 目標可用三種單位：× 需求、mL、g。
- 按「套用」後依調整方式反推：

  | 路徑 | 預設 | 也可選 |
  |---|---|---|
  | 線與圖樣 | 調壓力（P300 調轉速），到極限才改速度 | 只調速度 |
  | 單點 | 調開膠時間 | 調壓力 |

  提示會寫出改了哪個設定。

- 頂部工具列：「自動最佳化」「情境比較」（v1.7 移除與最佳化重疊的「圖樣比較」）。
- 說明：介面上的「?」游標移過去（手機點一下）才顯示說明。

播放：空白鍵播放／暫停，← → 步進；拖曳時間軸、點曲線或時間軸上的標記（關膠、到位、抬針、退離）可跳轉；游標在曲線上移動會顯示當時的數值。播放倍率只影響觀看速度。

復原與保存（v3.0）：每次變更設定記一步，右上箭頭或 Ctrl+Z／Ctrl+Y 復原、重做。設定自動存在瀏覽器，下次開啟接著用；結果卡最下方可匯出配置 JSON、用「匯入配置」讀回，或匯出一頁 HTML 報告（可列印成 PDF）。完整快速鍵見右上的鍵盤圖示。

計算進度：壓合、膠量反推與公差檢查在畫面上方顯示進度，可取消。

結果卡的提醒分兩區（v3.0）：「需要注意」是建議調整設定的項目（埋針、膠條被拉細、壓不到墊片、熱源內夾氣、PCP 超壓等），「模型界線與說明」是模型沒算到的部分。

壓合：「模擬壓合」顯示透明板以定力壓到墊片、膠膜擴散、氣泡（紅色）壓縮／遷移／排出，以及壓到墊片後的靜置回脹；時間軸標示壓合秒數與靜置秒數。右側列出覆蓋率、夾氣、溢出距離、溫升、熱阻、壓到墊片時間、氣泡封住／排出次數與回脹程度；可切換「前緣時序」著色、切換夾氣顏色（洋紅、藍、黃、黑）、保存壓合基準。

公差檢查（v3.0）：壓合後在結果卡輸入膠量公差（±%）與間隙公差（±mm，留空為間隙的 10%），會再壓兩次並與目標比較——「膠少・間隙大」看覆蓋與溫升最差的情況，「膠多・間隙小」看溢膠最多的情況。

情境：結果卡「存成情境」保存目前參數與壓合結果（未壓合會自動先算），右上「情境比較」依目標（覆蓋 ≥ 目標、溢膠 ≤ 上限，達標者膠量越少越前）排序全部情境，可載入、改名、刪除、匯出 CSV／JSON、匯入 JSON；情境存在瀏覽器的 localStorage。

自動最佳化（製程窗口）：頂部「自動最佳化」固定圖樣、熱源、間隙、膠材、加速度、針距、收尾與壓合條件，搜尋間距（蛇形／螺旋）與邊界內縮；直線與單點沒有圖樣幾何，只搜尋膠量窗口（v1.4）。每組幾何找出膠量窗口（左界＝達到覆蓋目標的最少膠量，右界＝溢膠不超過上限的最多膠量），標稱膠量需在 ±容差（預設 ±10%）內兩界都成立才算達標；前 3 名以設定網格在 −容差／標稱／+容差 複核。膠量預設以驅動壓力（R75，10–100 psi）或 PCP 轉速（P300，10–150 rpm）在目前速度下調整，到極限才改速度（單點改開膠時間）；也可只調速度（單點：開膠時間）並設週期上限。調整方式與膠量列共用。針嘴可固定，或選「自動」與移動速度一起依出膠能力與膠條選（v1.8，見下）。

v1.6 起有「搜尋變數」表：

- 圖樣種類（蛇形、螺旋、米字形、單點、中心線）、路徑間距、邊界內縮、螺旋起點、移動速度、針嘴，每個都能選「固定」或「搜尋」，範圍可自訂。
- 每種圖樣的最佳組都會找膠量窗口；v2.0.1 起也都會複核，每種圖樣都有確定的判定。
- v2.0.1：最差溢膠離上限不到一個複核網格的達標組標「邊緣達標」，同一段膠量內排在穩健的後面。

v1.8 起針嘴（預設「自動」）與移動速度（預設「搜尋」）不再逐一壓合，而是每組幾何先用解析解選好：

- 針頭只試整數 G 數（25G 0.25 mm 到 8G 3.43 mm，共 16 種）；1/8 吋（Laird 指南用嘴）只在設備頁手動選。
- 條件：只靠壓力（轉速）就鋪得出整個膠量範圍（預設容差時 0.94–1.40× 需求）。
- 選法：膠條最接近針嘴大小、週期不超過週期上限（未設定時以 30 s 為參考），成本相近時選週期短的。
- 走完路徑在速度範圍內都超過 180 s 的組合先略過；出不了需要膠量的組合在表格標示「設備上限 x×」。
- 達標者先依膠量分段（從最少膠量起每 3% 一段），同一段內依膠條、疊膠碰針、週期、壓力餘裕排序。

鋪膠與疊高（v1.9）：圖樣與直線的膠依出膠順序一格一格鋪到約 0.1 mm 的膠面上（`src/deposit.js`）。
- 每一小步的膠是針嘴正下方、與膠條同寬的圓盤（v2.1）：直線上加起來就是半橢圓橫切面，轉角外側圓、內側多一點，起點終點是圓頭。
- 後面那趟落在先前的膠上，膠量逐格相加。
- 針嘴離下面的膠變近時，新膠條被壓成剩下的間隙高、變寬（與單趟被針嘴壓平同一規則）。
- 高出針尖的膠被針管前半圈推到兩側（外徑依針頭規格表）。
- 3D 膠形、結果卡「膠高 / 寬」的疊高、自動最佳化的「疊膠碰針」與壓合的起始膠面都讀這一份。針尖碰到先前那趟的膠時警告；針頭沾膠、拖絲沒有算。

v1.8.2–v1.8.3 的疊高檢查與 3D 疊膠各用一套近似，已由這份膠面取代。

針嘴離面高度（v3.1）：針嘴碰到膠的結果不能用——一趟的膠高於針嘴（埋針），或路徑重複經過時碰到前一趟疊起來的膠。

- 搜尋變數表的「針嘴離面高度」預設「自動上調」：每次試算若會碰到，就把針嘴提高 1 mm 重算，直到不碰為止（最高 20 mm）；壓合從那個針距鋪出的膠形開始。
- 複核時整個容差範圍用同一個針距：膠量最多那一點需要的高度。結果表的膠條欄寫出「針距 x mm（+n）」，套用時一併設定。
- 選「固定」：維持目前針距，會碰到的結果判為「碰針」，不算達標。
- 調到比膠條自然高度的 2 倍還高時標「偏高」：膠會先懸空再落下、落點偏後，模型沒有算；同樣膠量時這種組合排在後面。
- 模型沒有算膠堆自重攤平，疊高偏高（米字形中心最明顯），上調的量偏保守。

v1.5 起有四個精細度：快速、標準、精細、極精細。差別在候選數、找窗口與複核的組數、容差內的複核點數與網格。

- **時間估算**：選級時依這台電腦試算一次估出時間。
- **並行**：搜尋分散在多個 Worker 執行。
- **停止**：搜尋中按「停止搜尋」，會保留已完成的部分結果。
- **達標條件**：只有在細網格、容差內多個膠量都達標的結果才算「達標」。
- **套用**：網格會設成該結果使用的網格。

這是模擬器上的數值搜尋，不是統計學習；設計理由見上層第 24、26 份文件。

針嘴與膠形：同樣每 mm 膠量下，膠條的高與寬由針嘴離面高度決定；針嘴內徑決定出膠量與膠條品質。

- 針距低於膠的自然高度時，膠被壓成針距高、較寬的扁條（截面積不變）。
- 壓平寬度以「內徑 + 2 × 針距」為上限（AI 初估）；再壓不開時，膠高於針距，標示「埋針」。
- 結果卡另顯示拉細倍率（針嘴內孔截面 ÷ 實際膠條截面＝平均移動速度 ÷ 出膠速度）與匹配內徑 √(4A/π)（A＝每 mm 路徑膠量），0.7–1.5 為 AI 初估的良好範圍。

時間曲線：退離完成後的灰色區域是尾膠結算（關膠後衰減出膠積分 20 個時間常數，讓帳目閉合），不是機台等待；週期時間以「動作完成」計。

視角：全機、工作區、機頭、供膠站（P300）、近看、熱源特寫、跟隨；①–④ 等角方向、360° 自由旋轉、正交／透視切換、深色／淺色主題。近看與熱源特寫會隱藏上方機構，不改變任何尺寸。

## 模型摘要

| 項目 | 方法 | 界線 |
|---|---|---|
| R75 putty 流量 | TDS 75 g/min @ 90 psi × 冪律管流 Q ∝ P^m·d^(3+m)/L^m，m = 2.7 取自 Laird 910 點膠指南曲線 | 指南與 TDS 的流率單位待 Laird 確認；未含溫度 |
| R75 grease | 冪律管流 Q = πn/(3n+1)·(ΔP/2KL)^(1/n)·R^(3+1/n)，K = 2500 Pa·sⁿ（TDS Brookfield 2 rpm，約 1 s⁻¹），n = 0.4 比照 Laird 同類膏體曲線（v2.0；舊版為常黏度） | n 為 AI 初估；Brookfield 剪切率換算使絕對出膠量不確定約 5 倍，請用兩種壓力實測校正 |
| 起停與機台設定 | 延遲 + 一階「氣壓」時間常數，出膠量跟著壓力的 m 次方 Q ∝ P^m（v2.2：起膠損失 H_m·τ、殘壓出膠 τ/m）；氣壓式時間常數隨膠筒空氣體積放大；起點出膠等待（Feed On Delay） | 時間常數為 AI 初估，需秤短線／長線校正 |
| P300 | 理想容積計量 0.3 mL/rev；v2.2 起以冪律算針頭出口壓力，超過 PCP 最高工作壓力 290 psi 時警告，膠量反推與最佳化的轉速上限也以此為界 | 滿腔、無滑漏、無管路壓降 |
| 起停 | 延遲 + 一階響應解析積分 | 時間常數為 AI 初估 |
| 運動 | 梯形速度；多段路徑轉角依 junction deviation 減速；圓弧段另受向心加速度限制 v² ÷ 半徑 ≤ 加速度（v3.0） | 通用近似，非特定控制器；沒有 jerk 限制 |
| 膠溫（v3.0） | 稠度 K(T) = K(23 °C)·exp(Ea/R·(1/T − 1/296 K))，作用在出膠、PCP 針頭壓力與壓合 | 活化能為 AI 初估（Tputty 16、Tgrease 30 kJ/mol），需兩個膠溫秤重校正 |
| 膠形 | 半橢圓膠線（共享截面環）、球冠膠點，體積守恆；針距低於自然高度時壓成針距高（寬度以內徑 + 2 × 針距為限） | 幾何重建，非潤濕或拉絲求解；壓平範圍為 AI 初估 |
| 壓合 | 定力壓到墊片的 Hele-Shaw 擠壓，膜流用與出膠相同的冪律（v2.0，以圓盤解析解驗證 0–3%）；v2.2 加入 Bingham 降伏應力（平板塑性極限，力不夠時壓板停在墊片上方，圓盤解析解驗證 < 6%）與保壓時間上限；夾氣依 pV = 常數 隱式聯立，介面雙向移動（壓縮、遷移、排出），墊片定位後依降伏應力回脹 | 降伏應力以加成近似（流動中略低估）；未含壁滑；指狀穿透以網格一階近似，夾氣數量對網格敏感 |
| 熱阻 | (實際膠層/k + TDS 推算接觸熱阻) ÷ 濕潤面積；v2.2 起膠層用壓合實際停住的厚度 | 一維，不含擴散熱阻 |
| 公差檢查（v3.0） | 膠量 ± 與間隙 ± 配成「膠少・間隙大」「膠多・間隙小」兩個最差情況，各壓一次 | 間隙為均勻變動，不含傾斜與翹曲 |
| 壓合校正（v3.0） | 定體積圓盤定力壓合的封閉解（Scott 1931）加 Bingham 塑性極限，由膠點攤開的直徑反推 K 或降伏應力 | 需要平行的透明板與已知的力 |

完整參數與出處在介面右上「來源」；v1.0／v1.1 查證後的更新放在 `src/parameters.js`，研究原檔 `../data/engineering_defaults_v0.3.json` 保持不變。

## 程式結構

| 檔案 | 內容 |
|---|---|
| `src/engine.js` | 流量、起停、沉積、收尾、體積帳目；不逐步模擬的沉積與時間（runTiming）、出膠量校正 |
| `src/motion.js` | 梯形運動、轉角前瞻規劃、圓弧的向心加速度上限 |
| `src/path-planning.js` | 依熱源產生路徑（含米字形） |
| `src/compression.js` | 壓合（定力 Hele-Shaw、可壓縮夾氣、靜置回脹）、熱阻 |
| `src/stacking.js` | 重複經過處的膠疊高與針嘴碰膠檢查 |
| `src/calibration.js` | 膠點壓合的封閉解與壓合流變擬合（稠度 K、降伏應力） |
| `src/tolerance.js` | 公差檢查的情況、沉積縮放與判定 |
| `src/tuning.js` | 依目標膠量反推壓力／轉速（到極限改速度或開膠時間）、速度、開膠時間；對數空間夾擠割線法 |
| `src/optimize.js` | 目標判定與排序、製程窗口搜尋（四個精細度、可並行、可停止）、時間估算、針嘴與速度選擇（chooseProcess） |
| `src/compute-worker.js` | 壓合、膠量反推、最佳化單次評估與計時的背景計算（最佳化時開多個） |
| `src/parameters.js`、`src/materials.js` | v1.0 參數更新與材料卡 |
| `src/scene.js` | 3D 場景、膠形、相機 |
| `src/machine.js`、`src/scene-parts.js` | 桌上型點膠機、周邊與針頭；機械元件（鋁擠型、滑軌、滑塊、馬達、螺桿、標籤） |
| `src/cartridge-assembly.js`、`pcp-head.js`、`pump-station.js`、`c300-enclosure.js` | 依公開尺寸的設備外形 |
| `src/compression-scene.js` | 壓合視覺化 |
| `src/main.js`、`src/ui/`、`src/style.css` | 介面（`ui/report.js` 為 HTML 報告） |
