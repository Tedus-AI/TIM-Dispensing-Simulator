# TIM 點膠研究室 v1.0

本機工程假設原型，**未經實機校準**。模擬 Laird Tputty 910／Tgrease 2500 在 R75 氣壓時間式或 P300 PCP 容積式設備上的點膠、收尾、透明板壓合與一維熱阻，用於比較方案、縮小試驗範圍，不能取代首件或量產驗證。本版修正與查證見 [第 22 份：v1.0 接手全面修正與驗證](../22_v1.0接手全面修正與驗證.md)。

## 開啟

Windows：雙擊本資料夾的 **啟動模擬器.cmd**，瀏覽器開啟 `http://127.0.0.1:5173/`。只需 Node.js；建置檔已附於 `dist/`，執行時不連外部 CDN，工件不上傳雲端，只監聽本機。

開發：

```powershell
npm ci
npm test        # 75 項數值、幾何與壓合測試
npm run dev     # 開發伺服器，與啟動器共用 5173，請勿同時開
npm run build   # 更新 dist/
```

## 操作流程

1. **設備**：膠材、架構、壓力（psi／bar）或轉速、虛擬針嘴。每個欄位都標示「TDS／推導／AI 初估／幾何」。
2. **熱源**：元件接觸面的形狀、尺寸、中心、組裝間隙與功耗。可按「自動調整移動速度」讓膠量 = 間隙體積 × 係數。
3. **路徑**：依熱源（中心線、N、蛇形、螺旋、外框）、直線或單點；設定速度、加速度與轉角減速。
4. **收尾**：提前關膠、終點停留、退離方式、PCP 反轉。
5. **工件**：尺寸、治具高度，或匯入 STL／GLB／內嵌 glTF。

播放：空白鍵播放／暫停；拖曳時間軸、點曲線或時間軸上的標記（關膠、到位、抬針、退離）可跳轉。播放倍率只影響觀看速度。

壓合：「模擬壓合」顯示透明板下降、膠膜擴散與夾氣（紅色），右側列出覆蓋率、夾氣、溢出距離、溫升與熱阻；可切換「前緣時序」著色、保存壓合基準。「比較所有圖樣」在等膠量下比較五種圖樣並可一鍵套用。

視角：全機、工作區、機頭、供膠站（P300）、近看、熱源特寫、跟隨；①–④ 等角方向、360° 自由旋轉、正交／透視切換、深色／淺色主題。近看與熱源特寫會隱藏上方機構，不改變任何尺寸。

## 模型摘要

| 項目 | 方法 | 界線 |
|---|---|---|
| R75 putty 流量 | TDS 75 g/min @ 90 psi × 冪律管流 Q ∝ P^m·d^(3+m)/L^m，m = 2.7 取自 Laird 910 點膠指南曲線 | 指南與 TDS 的流率單位待 Laird 確認；未含溫度 |
| R75 grease | 常黏度 2500 Pa·s Poiseuille | 單點黏度，非完整流變 |
| P300 | 理想容積計量 0.3 mL/rev | 滿腔、無滑漏、無管路壓降 |
| 起停 | 延遲 + 一階響應解析積分 | 時間常數為 AI 初估 |
| 運動 | 梯形速度；多段路徑轉角依 junction deviation 減速 | 通用近似，非特定控制器 |
| 膠形 | 半橢圓膠線（共享截面環）、球冠膠點，體積守恆 | 幾何重建，非潤濕或拉絲求解 |
| 壓合 | 平行板 Hele-Shaw 擠壓，被包圍乾區視為夾氣 | 無屈服應力、壁滑、壓合力、氣體壓縮 |
| 熱阻 | (間隙/k + TDS 推算接觸熱阻) ÷ 濕潤面積 | 一維，不含擴散熱阻 |

完整參數與出處在介面右上「來源」；v1.0 查證後的更新放在 `src/parameters.js`，研究原檔 `../data/engineering_defaults_v0.3.json` 保持不變。

## 程式結構

| 檔案 | 內容 |
|---|---|
| `src/engine.js` | 流量、起停、沉積、收尾、體積帳目 |
| `src/motion.js` | 梯形運動與轉角前瞻規劃 |
| `src/path-planning.js` | 依熱源產生路徑 |
| `src/compression.js` | 壓合（Hele-Shaw）、夾氣、熱阻 |
| `src/tuning.js` | 依目標膠量反推速度／開膠時間 |
| `src/compute-worker.js` | 壓合與圖樣比較的背景計算 |
| `src/parameters.js`、`src/materials.js` | v1.0 參數更新與材料卡 |
| `src/scene.js`、`src/scene-parts.js` | 3D 場景、龍門機構、相機 |
| `src/cartridge-assembly.js`、`pcp-head.js`、`pump-station.js`、`c300-enclosure.js` | 依公開尺寸的設備外形 |
| `src/compression-scene.js` | 壓合視覺化 |
| `src/main.js`、`src/ui/`、`src/style.css` | 介面 |

## 匯出

配置 JSON（完整設定、來源、v1.0 參數更新、壓合與熱阻摘要、圖樣比較）、結果 CSV（每 10 ms 快照，第一列附中繼資料）、畫面 PNG（附未校準標記）。工件檔只保存名稱與雜湊。
