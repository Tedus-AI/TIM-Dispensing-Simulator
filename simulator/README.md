# TIM 點膠研究室 v0.4

本機工程假設原型，未經實機校準。v0.4 依原廠圖面改進裸膠筒、候選針嘴、C300 參考機櫃、DM-22 供膠站及 PCP 候選機頭，加入可動管路及多種設備視角。詳見 [v0.4 來源與尺寸](../19_v0.4原廠外形尺寸與機構驗證.md)。研究資料位於上層專案資料夾。

2026-10-26：直線預設提前 10 mm 關膠（新增 AI 初估，非原廠配方），可一鍵切回「未補償 · 0 mm」。收尾控制在左側路徑與運動下方；若看不到，向下捲動左側配置欄。距離依當前加減速曲線換算成關膠時間，針嘴仍走到原終點。請同時檢查完整膠量、停止後尾膠與末段／中段平均截面比；超過路徑全長的提前距離會使本次不開膠並提示。單點不使用此設定。

新版測試、畫面及數值見 [v0.2 更新與驗證](../17_v0.2收尾控制與驗證.md)。

## 開啟

雙擊本資料夾的 **啟動模擬器.cmd**，會開啟 `http://127.0.0.1:5173/`。使用現有 Node.js，無需登入。建置檔已附於 dist；執行時不需要外部 CDN，也不把工件上傳到雲端。只監聽本機位址。

開發用途：`npm ci`、`npm test`、`npm run dev`；更新正式檔案用 `npm run build`。啟動器在背景執行本機服務；再次啟動會重用。關閉瀏覽器不等於停止服務；Windows 重開機後可再次雙擊啟動器。

## 使用

1. 選 Tputty 910 或 Tgrease-2500，以及 R75 氣壓時間式或 P300 理想 PCP。
2. 選單點／直線，修改壓力或轉速、路徑與速度。數值輸入後按 Tab 或點其他位置套用；不在一個未輸完的數字上計算。
3. 按開始試驗；可暫停、單步及拖動時間軸。預設 0.5 倍播放只讓動作易看，不改計算結果。
4. 切全機／工作區／機頭／供膠站／近看／局部跟隨，選四個等角方向；供膠站視角僅 P300 可用。按 360° 自由旋轉後左鍵拖曳旋轉、右鍵平移、滾輪縮放；選等角方向可重新鎖定。自由模式可以繞到背面與下方；正上／下極點保留很小角度以避免翻轉。
5. 保存基準後再改參數，查看完整試驗量差與配置差異。各材料／架構暫存覆寫僅保留於此頁面工作階段；重整會重設，請匯出保存。
6. 工件區可載入 STL、GLB 或內嵌資源 glTF，並核對長寬厚。STL 必須選單位／上方向；GLB 依公尺和 Y 向上換算。STEP 和外接資源 glTF 尚未支援。

## 已做與能力界線

- 真實毫米比例、同一狀態驅動畫面與讀值。近看隱藏上部機構，不改物件比例。
- 材料流量起停、梯形／三角速度路徑、尾膠積分、PCP 計量暫存、庫存耗盡。
- 單點球冠；直線以共享截面組成連續半橢圓膠線。沿路徑以嘴徑寬三角權重分配每步體積，再以網格積分正規化總體積；局部形狀仍是明示的工程幾何假設，不是實際接觸角或流體求解。
- 工件沉積量與幾何網格總體積對帳；出口量分為工件沉積與離面後形狀未定量。直線末端因持續尾膠可能高於針距，會標出超出簡化形狀範圍。
- 工件匯入為尺寸、姿態與顯示能力；目前固定放置於治具、點膠面取工件上方水平參考面。**不能宣稱已驗證孔洞、曲面、斜面、完整碰撞或可靠實機預測。**
- 機架、夾持與外殼是工程示意，未具備品牌機台精確 CAD；有效工作範圍與來源分開保存。
- 沒有真實壓降、屈服、溫度效應、壁滑、拉絲、塌陷、噴嘴負壓、壓合或空洞求解。PCP 僅以未出嘴暫存量進行理想回收近似。
- 管路持膠量計入帳目；可見軟管只示意端點連接，不能當作實際長度、內外徑、彎曲半徑、耐壓或已驗證配管。
- 配置 JSON 保存完整來源／假設與相機資訊；工件只保存名稱與雜湊，重現需原檔。CSV 保存每個快照及配置中繼資料；圖片保留未校準標記，詳細假設搭配配置 JSON 使用。

## v0.3 視覺與時序

R75 裸筒外觀使用 Nordson 75 cc 43.2 × 98.8 mm 資料；候選 7018555 塑膠嘴總長 63.5 mm，插入長假設 7 mm、外露 56.5 mm，與 10 mm 等效流道分離。舊版泛用 Blender 金屬接頭原始 `.blend` 留在 `assets-source/nozzle_adapter/`，不再畫在 R75 直接鎖入式針嘴與膠筒之間。兩種材料的顏色對照官方色名；實際 RGB、金屬材質、夾具和機架均為視覺近似，不是原廠精確 CAD。

到位後停留（預設 0.1 s，AI 初估）才開始垂直、斜退或先抬後退；橙色虛線是針尖路徑而非膠絲。PCP 反轉預設 0（停用），30 rpm、0.05 s 僅是比較用 AI 初估。此版不同退離方法不會預測拉絲或落點差異，離面後出膠另列形狀未定。動作完成後仍可能持續數值記帳，不能把完整播放時間當生產節拍。

## v0.5 透明板壓合驗證
左側新增熱源尺寸、形狀、位置與組裝間隙設定；可查看透明板及估算等效覆蓋、保存基準比較，並隨 JSON/CSV 匯出摘要。模型為未校準的體積守恆幾何啟發式，不能取代實測；詳細方法、限制與校準資料請見 ../20_v0.5透明板壓合驗證與校準.md。

## v0.6 依熱源規劃點膠路徑
可按熱源尺寸與位置生成中心線、N、蛇形、螺旋和外框，並同步點膠和壓合結果。邊界內縮與間距為工程初估；轉角、壓合流動、排氣和膠線交疊未經實測校準。廠商參考與限制見 ../21_v0.6熱源路徑廠商研究與模型限制.md。

## v0.7 螺旋形狀與方向
螺旋可選依熱源、方形／矩形或圓形，並可選外向內或中心向外。圓形螺旋使用熱源可容納的內接圓，圓形熱源的方形螺旋使用內接正方形；路徑為針尖中心線，膠寬及壓後膠材仍可能越界。起停與壓合採用重新計算的路徑；仍是未校準近似。
