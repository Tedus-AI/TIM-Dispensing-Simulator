v1.0.0：接手後全面修正計算與介面——Tputty 壓力冪次改依 Laird 點膠指南曲線（m = 2.7）、多段路徑轉角減速、Hele-Shaw 壓合與夾氣、一維熱阻／溫升、圖樣比較與自動調速，以及彩色 3D 與全新工作台介面。詳見 [第 22 份：v1.0 接手全面修正與驗證](22_v1.0接手全面修正與驗證.md)。

**工程假設／尚未經實機校準。** 本版用於比較明示假設下的參數、路徑與壓合方案，尚不能可靠替代真機試驗。膠材初始值、推估與來源均保留註記。

## 開啟模擬器

**網頁版（免安裝）：https://tedus-ai.github.io/TIM-Dispensing-Simulator/**　main 分支的 `simulator/` 更新後，由 GitHub Actions 自動測試、建置並部署到 GitHub Pages。

本機版：
Windows 安裝 Node.js 後，雙擊 `simulator/啟動模擬器.cmd`，瀏覽器開啟 http://127.0.0.1:5173/ 。本版附有建置檔 `simulator/dist`，可直接啟動，不必先安裝開發套件。服務只監聽本機；工件在本機讀取。

重新開發／建置：

```powershell
cd simulator
npm ci
npm test
npm run build
npm run dev
```

開發服務與正式啟動器使用同一個連接埠，請勿同時啟動。

## 本版功能

- Tputty 910、Tgrease 2500；R75 氣壓時間式、P300 理想 PCP。
- 依熱源路徑（中心線、N、蛇形、螺旋、外框）、直線、單點；轉角依 junction deviation 減速。
- 出膠起停、提前關膠、退離動作、PCP 反轉、庫存與體積對帳。
- 透明板定力壓到墊片的動畫：膠膜擴散、氣泡壓縮／遷移／排出、靜置回脹；覆蓋率、夾氣、溢膠距離、壓合時間、熱阻與溫升。
- 膠量列：依目標膠量自動調壓力／轉速（到極限才改速度）或速度、開膠時間；五種圖樣等膠量比較；情境比較；製程窗口自動最佳化（圖樣、直線、單點）。
- 彩色 3D：桌上型龍門、拖鏈、控制器即時顯示、C300／DM-22／PCP 參考外形；正交等角 ①–④、自由旋轉、透視、熱源特寫與跟隨。
- STL、GLB、內嵌 glTF 工件匯入；配置 JSON、結果 CSV、畫面 PNG 匯出；深色／淺色主題。
