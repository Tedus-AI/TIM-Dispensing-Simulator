**v3.1.0**（2026-11-11）：預設值與自動最佳化的針嘴高度條件。
- 終點前關膠距離預設改為 0 mm（到終點才關膠）；收尾頁保留「比較值 10 mm」。

v3.0.0（2026-11-10）：第三次全面複查——程式審查、物理真實性、介面與 3D 機台。
- **修正的缺陷**
  - 氣泡被另一個氣泡包住時（外向內螺旋、外框類圖樣），v2.2 把內層氣泡的保持壓力算成無限大：壓板可能停在遠高於墊片處，或氣泡被算到 10–20 個大氣壓。已修正。
  - 圓螺旋、圓外框的速度原本可超過加速度上限 3.5–4.6 倍；加上向心加速度上限 v² ÷ 半徑 ≤ 加速度。高速圓弧的實際週期較長、每 mm 膠量較多。
  - 降伏應力撐住壓板的厚度原本偏薄約 4%，現在對解析解在 1% 內。
- **新增的物理**
  - 膠溫：膏體越熱越稀。氣壓式膠量每 °C 約變 6%（Tputty）到 11%（Tgrease），活化能為 AI 初估。
  - 用透明板實測校正壓合：一顆膠點、已知的力與時間、量攤開的直徑，反推壓合用的稠度或降伏應力。
  - 公差檢查：膠量與間隙公差一起看最差情況（覆蓋與溫升最差、溢膠最多）。
- **介面**：復原／重做、設定自動保存與匯入、計算進度與取消、「需要注意」與「模型界線」分開、曲線讀值、快速鍵、HTML 報告。
- **3D 機台**：依實際桌上型點膠機的構造重畫（鋁擠型橫梁、線性滑軌與滑塊、滾珠螺桿、步進馬達、拖鏈、操作面板、教導盒、氣壓控制器與腳踏開關、魯爾鎖針頭依 G 數上色）；P300 機櫃加防護窗。
- **準確度**：數值解對同一組方程式的解析解在 2% 以內；對實機的準確度取決於尚未校正的膠材參數，未校正時絕對膠量可能差數倍。逐項的不確定度與校正方法見第 35 份第 4 節。

詳見 [第 35 份：v3.0 三次全面複查](35_v3.0三次全面複查_物理介面與機台.md)。

v2.1.1（2026-11-07）：夾氣畫成貫穿膠層的洞。
- 模型裡的夾氣都上下貫穿（碰到透明板也碰到工件），透明板上看到的是一塊沒有膠的區域。原本畫成膠面上的凹痕，看起來像空氣被一層膠蓋住。
- 現在空氣過半的格子畫成穿透膠層的洞，洞壁落在格子交界上，洞裡依氣泡的面積塗上夾氣顏色；氣泡邊緣、空氣不到一半的格子仍留在膠面上，淡淡上色。
- 詳見第 33 份第 7 節。

v2.1.0（2026-11-06）：轉角與端點的膠形、夾氣顯示。
- **膠形**：每一小步的膠改成落在針嘴正下方的圓盤。直線膠條的橫切面不變（仍是半橢圓），轉角外側變圓、內側只多出兩段落點重疊的部分，起點和終點都是圓頭。原本轉角外側缺一角、內側疊兩層，3D 裡看起來像兩片鰭，起點和終點也有一圈圈的台階，這些都是鋪膠方法造成的假形狀。
  - 間隙 0.5 mm 的 Tputty 螺旋：覆蓋 96.4% → 97.1%，夾氣 28.5 → 22.6 mm²；
  - 間隙 0.05 mm 的 Tgrease：差不到 0.2 個百分點。
- **夾氣顯示**：壓合後的膠層直接依每格的空氣比例染成選定的夾氣顏色。間隙較厚時，原本的色塊會被膠層蓋住，被壓小的氣泡也完全沒畫，所以只看得到凹痕。
- **自動最佳化**：膠條欄加上針嘴內徑。

詳見 [第 33 份：轉角與端點膠形、夾氣顯示](33_v2.1轉角與端點膠形_夾氣顯示.md)。

v2.0.0（2026-11-06）：全面複查實機參數、出膠物理與壓合物理。
- **Tgrease 2500 出膠改為剪切變稀的冪律**：舊版把 Brookfield 2 rpm 的 2500 Pa·s 當成固定黏度。Laird 自家膏體的流量—氣壓曲線顯示流量 ∝ 壓力^2.4–2.7，高填充膏體強烈剪切變稀。細針頭、高壓力時出膠量比舊版多很多，自動最佳化會選較細的針頭。
- **壓合與出膠用同一條流變**：以圓盤壓合的解析解驗證（誤差 0–3%）。膠接近墊片時流得很慢、黏度很高，以 10 kgf 壓到 0.05 mm 要很久，實際膠層可能停在比墊片厚處，結果卡會提醒。
- **補上實機設定**：起點出膠等待（Feed On Delay）；氣壓式膠筒越空、起停反應越慢；間隙接近最小膠層厚度時警告。
- **校正**：可用兩種壓力各秤一次出膠量，同時擬合稠度與剪切變稀指數。

詳見 [第 31 份：全面複查](31_v2.0全面複查_實機參數出膠與壓合物理.md)，含實機參數對照表與上機校正清單。

## 開啟模擬器

**網頁版（免安裝）：https://tedus-ai.github.io/TIM-Dispensing-Simulator/**　main 分支的 `simulator/` 更新後，由 GitHub Actions 自動測試、建置並部署到 GitHub Pages。

本機版：
Windows 安裝 Node.js 後，雙擊 `simulator/啟動模擬器.cmd`，瀏覽器開啟 http://127.0.0.1:5173/ 。本版附有建置檔 `simulator/dist`，可直接啟動，不必先安裝開發套件。服務只監聽本機；工件在本機讀取。

重新開發／建置：

```powershell
cd simulator
npm ci
npm test
npm run build
npm run dev
```

開發服務與正式啟動器使用同一個連接埠，請勿同時啟動。

## 本版功能

- Tputty 910、Tgrease 2500；R75 氣壓時間式、P300 理想 PCP。
- 依熱源路徑（中心線、N、蛇形、螺旋、外框）、直線、單點；轉角依 junction deviation 減速。
- 出膠起停、提前關膠、退離動作、PCP 反轉、庫存與體積對帳。
- 透明板定力壓到墊片的動畫：膠膜擴散、氣泡壓縮／遷移／排出、靜置回脹；覆蓋率、夾氣、溢膠距離、壓合時間、熱阻與溫升。
- 膠量列：依目標膠量自動調壓力／轉速（到極限才改速度）或速度、開膠時間；情境比較；製程窗口自動最佳化（可搜尋圖樣種類、間距、內縮、螺旋起點；針嘴與移動速度每組自動選）。
- 彩色 3D：桌上型點膠機（鋁擠型橫梁、線性滑軌、滾珠螺桿、步進馬達、拖鏈、操作面板、教導盒）、氣壓控制器即時顯示、依 G 數上色的針頭、C300／DM-22／PCP 參考外形；正交等角 ①–④、自由旋轉、透視、熱源特寫與跟隨。
- STL、GLB、內嵌 glTF 工件匯入；配置 JSON（可匯入）、結果 CSV、畫面 PNG、HTML 報告匯出；深色／淺色主題。
- 膠溫、公差檢查、壓合實測校正；復原／重做、設定自動保存、快速鍵。
